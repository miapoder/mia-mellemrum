# Mellemrum

Mellemrum er en React-baseret kultur- og eventplatform for lokale oplevelser i Aarhus. Platformen samler koncerter, talks, workshops og fællesskaber ét sted, så brugere nemt kan opdage nye oplevelser og tilmelde sig events.

## Om projektet

Projektet er udviklet som en del af Case 1 – Fra prototype til produktionsklar React-løsning.

Formålet med casen har været at videreudvikle en eksisterende React-prototype til en mere robust, tilgængelig og vedligeholdelsesvenlig løsning. Undervejs er der arbejdet med blandt andet React-arkitektur, UI-konsistens, accessibility, performance, Supabase, fejlhåndtering og deployment.

## Hvad kan man på Mellemrum?

På siden kan brugere:

- Se kommende events i Aarhus
- Søge efter events
- Filtrere events efter kategori
- Se detaljer om det enkelte event
- Se dato, sted og antal tilmeldte
- Tilmelde sig events
- Læse mere om Mellemrum og platformens målgrupper

Der findes også et internt overblik over tilmeldinger.
